# AnalystLab Africa - Data Analytics Internship

This repository contains the deliverables for the Data Analytics internship tasks, focusing on Data Cleaning, Exploratory Data Analysis (EDA), and Executive Reporting.

---

## 📌 Projects Included

### 1. Netflix Movies & TV Shows Analysis
* **Objective:** Cleaned and analyzed the Netflix dataset to uncover trends in content addition, genre distribution, and rating patterns over the years.
* **Deliverables:**
  * Jupyter Notebook (`netflix.ipynb`) with full Python EDA code.
  * Cleaned Dataset (`Cleaned_Netflix_Data.xls`).
  * One-Page Executive Summary Report (`Netflix_Strict_One_Page.pdf`).

### 2. Online Retail E-Commerce Analysis
* **Objective:** Performed data cleaning and customer transaction analysis on an e-commerce dataset to identify sales trends and key performance metrics.
* **Deliverables:**
  * Jupyter Notebook (`onlineretail.ipynb`) with complete data processing.
  * Cleaned Dataset (`Cleaned_Online_Retail_Data.xls`).
  * One-Page Summary Report (`onlineretail.pdf`).

---

## 🛠️ Tools & Technologies Used
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook
* **Reporting:** PDF Executive Summaries
